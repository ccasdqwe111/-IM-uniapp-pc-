# 支持推送IM即时通讯 uniapp+pc 自建音视频通话聊天软件

源码获取：ym7k.com/19162/

这套是私有化部署 IM 即时通讯系统，UniApp 移动端 + PC 网页端配套，自带私有消息推送、一对一私聊、群聊、实时音视频通话，不走第三方 IM SaaS，数据全部自持，适合做内部沟通、私域社群、客户客服、交友搭子配套通讯模块，源码可二次开发。

## ✅ 技术架构

- 移动端：UniApp（可打包微信小程序、APP、H5）
- PC 端：Web 网页端（Vue）
- 通讯底层：自研 IM 消息服务 / 可基于 WebSocket + Socket，支持离线消息推送
- 音视频：WebRTC 原生音视频，不用依赖第三方直播 SDK；支持一对一视频、语音通话
- 数据库：MySQL + Redis（Redis 做消息缓存、在线状态、离线队列）
- 服务端：Golang / Node 版本居多，长连接高性能，支持上万在线并发

> 
> 独立源码，私有化部署，非环信、融云这类第三方托管 IM

## ✅ 核心 IM 通讯功能

1. 消息收发：文字、表情、图片、文件、短视频、语音消息、定位卡片
2. 离线推送：离线消息缓存，上线自动拉取；支持对接厂商推送（个推 / 极光），APP 离线可收到消息提醒
3. 会话管理：会话列表、置顶会话、会话免打扰、会话删除、消息已读 / 未读标记
4. 单聊私聊：好友体系，添加好友、好友验证、拉黑、备注、资料卡查看
5. 群组聊天：普通群、大群；建群、邀请成员、踢出、群公告、群禁言、群管理员权限
6. 消息操作：消息撤回、消息转发、收藏消息、删除单条消息
7. 在线状态：在线 / 离线 / 忙碌状态展示

## ✅ 音视频通话模块（重点）

- 一对一语音通话、一对一视频通话
- 通话呼叫、接听、拒接、挂断、静音、关闭摄像头、切换前后摄像头（移动端）
- 通话等待提示、通话超时自动挂断
- WebRTC P2P 直连，支持内网穿透配置；可配置中转服务器（TURN）解决跨网不通问题
- 通话记录保存，后台可查看通话时长记录

## ✅ PC 网页端能力

PC 网页端和移动端消息实时互通，数据同步：

-扫码登录（UniApp 移动端扫码登录 PC）、账号密码登录
- 会话列表、收发图文文件、群聊
- PC 端发起 / 接收音视频通话，电脑摄像头麦克风直接调用
- 窗口消息弹窗提醒

## ✅ 后台管理系统功能

- 用户管理：账号新增、封禁、资料编辑
- 好友 & 群组管理：查看所有群、群成员管控、解散违规群
- 消息监控：消息记录查询（可开关消息存库）、敏感词过滤、违规消息拦截
- 推送配置：推送密钥、TURN 音视频中转服务配置
- 数据统计：在线人数、消息量、通话次数、活跃用户看板
- 权限配置、黑白名单

## ✅ 配套增值扩展（可按需二次开发）

- 红包、转账（对接支付）
- 阅后即焚消息
- 消息加密传输（端到端加密可选）
- 频道、分类社群
- 对接其他业务系统：搭子系统、客服系统、商城客服
- 聊天记录云端漫游、多端同步

## ✅ 变现 & 使用场景

1. 内部企业通讯、员工沟通工具
2. 同城搭子、社交平台内置聊天（就是你前面同城搭子系统配套 IM）
3. 私域客服系统，替代第三方客服
4. 源码售卖、搭建服务，给客户部署私有化聊天系统
5. 付费社群、知识付费圈子沟通工具
